What is ParcelMaker

ParcelMaker

TM

 is a 

reference implementation of IEC 62656-1

, for helping users to view, develop, and validate data dictionaries in the form of spreadsheets compliant to IEC 62656-1 on Microsoft® Excel®.

•

ParcelMaker

TM

 is developed by Toshiba with Visual Basic for Applications (VBA, in short). Your own codes can 

coexist

 with ParcelMaker

TM

.

•

For standardization purpose, ParcelMaker

TM

 is 

freely available

Tutorial for beginners

•

This tutorial shows how to describe a data dictionary by using ParcelMaker

TM

 with a simple example which uses only basic feature of IEC 61360-2/IEC 62656-1.

 Typical steps are as follows;

1..

Design your data dictionary,

2..

Prepare parcel sheets,

3..

Edit details of each concept,

4..

View the class hierarchy of your data dictionary,

5..

Validate your data dictionary.

(informative) Small tips

•

NOTE1: For information of advanced one, please look at IEC 61360-1/IEC 62656-2 (guide for IEC 61360-2/IEC 62656-1, respectively).

•

NOTE2: Parcel sheets of existing standardized data dictionaries will be available from the IEC CDD website.

(Informative) Small Tips (2/2)

•

Each parcel sheet has many cell columns. If there are many data lines in a parcel sheet, it may be difficult to know on which cell column you focus. In many cases, freeze rows/columns function provided by Microsoft® Excel® is useful. The function is available from 

View



Freeze Panes

.

•

TM

 does 

NOT

 disturb them as well as your own macros.
