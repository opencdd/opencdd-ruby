## What is opencdd?

`opencdd` is a pure-Ruby library for reading, writing, validating, and
navigating the IEC Common Data Dictionary (CDD) — the ISO/IEC 61360 /
62656-1 ontology used by `cdd.iec.ch`, ParcelMaker, and downstream
engineering and BOM tooling.

It is the Ruby core of the OpenCDD ecosystem, paired with TypeScript,
editor, and static-site components.

## Quick example

```ruby
require "opencdd"

db = Opencdd::Cddal.parse_file("oceanrunner.cddal")

# Powertype API — EngineType's valid configuration options
engine = db.find_by_code("AAA200")
engine.powertype?                            # => true
db.instances_of(engine).map(&:preferred_name)
# => ["Single Diesel Engine", "Twin Diesel Engine", "Electric Hybrid Engine"]

# Round-trip through Parcel Excel
Opencdd::Parcel::Writer.new(db).write("out.xlsx", parcel_id: "OCEAN")
db2 = Opencdd::Database.load("out.xlsx")
db.semantically_equal?(db2)                  # => true (for non-colliding IDs)
```
